# v0.7: readable single-hand notes

## Scope

- A completed cash hand can be opened from the table as readable text, copied, or downloaded as `.txt`.
- The view uses the hero's information boundary. Unrevealed opponent cards are absent.
- A color tag and freeform note are saved locally per hand and included in the text.
- JSON backup and restore remain available behind a secondary disclosure.
- The browser database upgrades from version 1 to 2 by adding an annotation store while retaining existing hand records.

## Checks

- 85/85 existing and new tests passed through the Node `Deno.test` adapter; Deno is unavailable on this machine.
- `node --check` passed for the changed JavaScript modules, and `git diff --check` passed.
- In the local in-app browser, a five-seat cash hand ended after the hero folded the small blind. The text showed the posted blinds, three bot folds, the hero's cards and fold, the uncalled 10-chip return, and the 20-chip contested pot. Unrevealed bot cards were absent.
- Yellow tag and note appeared in the text, survived closing and reopening the panel, then survived a full reload and saved-game continuation. Copy placed the complete text on the clipboard; Download .txt gave success feedback.

## Limits

- Text export covers the last completed hand in the current session. The JSON backup continues to cover all completed hands.
- Run it twice is not represented because the current engine records one board.
