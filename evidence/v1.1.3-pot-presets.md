# v1.1.3 pot size shortcuts — 2026-09-30

## Scope

The human betting controls offer 10%, 33%, 50%, 100%, and 150% pot shortcuts. They set the slider only; submitting still requires the action button. Facing a bet, the shortcut pays the call and sizes its raise against the pot after calling. A preset below the minimum legal bet or raise is disabled. A size above the callable cap uses the maximum legal amount.

## Checks

- JavaScript syntax and `git diff --check`: passed.
- Five test modules with the Node test shim: 91 passed, 0 failed. The new test checks pot-after-call sizing, invalid small bets, chip-unit rounding, stack caps, and a closed raise option.
- Isolated browser with a 10/20 six-seat cash table: the human faced a 20-chip call into a 30-chip pot. 10% and 33% were disabled; 100% selected 70 chips; 150% selected 95 chips; 50% selected 45 chips. The action label changed to Raise while the pot stayed at 30 before submission. No browser warnings or errors.
- At a 390px viewport, all five buttons measured 71×44 CSS pixels and the page scroll width remained 390px.

## Limits

The buttons are currently on the main local table. The old remote seat views retain their existing slider and step controls; the shared amount-control code accepts optional presets if those views are later updated.
