# v1.0 private cash practice gate

## Scope and decisions

- The daily flow is one human at a 2–6 seat local cash table with automatically assigned, session-stable rule bot styles.
- The latest completed hand opens as readable text with a color tag and note. JSON is a secondary backup and restore format.
- JSON backup now includes saved annotations; import accepts older backups without them, validates annotation keys and values, and adds missing hands and notes in one database transaction.
- Run it twice, rake, GTO scoring, and LLM agents remain outside v1.0.

## Evidence

- The Node adapter ran all 87 Deno-style tests: 87 passed, 0 failed. Deno itself is not installed. `node --check` and `git diff --check` passed.
- Earlier v0.6 evidence covers 6,000 mixed-style six-seat cash hands at 20, 40, 60, 100, 150, and 200 BB with zero invalid actions and chip conservation. The fixed style comparison tested all 1,326 two-card starts per style.
- The in-app browser completed one five-seat cash hand with a human and four bots at 10/20 blinds and 100 BB buy-in. The text matched the observed 10-chip small blind fold and uncalled return, and omitted opponents' hidden cards.
- The tag and note survived closing, reopening, a reload, and saved-session continuation. Copy returned the expected complete text; Download .txt reported success.
- A validated local JSON fixture containing one hand and one red-tagged note was restored through the browser file chooser. The app reported one hand and one note restored; the next backup reported two hands, up from one.
- After the local HTTP server was stopped, the cached v1.0 page loaded, continued the saved session, and displayed the existing hand text and note. The browser logged an expected service-worker update fetch error while offline; gameplay and review continued.

## Remaining limits

- The app offers the latest hand for text review; browsing older imported hands awaits the replay version. JSON restoration is for this app's backup format only.
- Download success was observed through the UI. The downloaded bytes were not independently compared with the copy buffer in this gate.
- Bot styles provide varied practice, not verified strategy advice. No GTO correctness claim is made.
