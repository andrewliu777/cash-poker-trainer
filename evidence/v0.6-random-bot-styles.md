# v0.6 / B2 random cash bot styles

Date: 2026-09-30. Base: `cb270ea` (v0.5/B1).

## Delivered

- Cash sessions shuffle four bot profiles: balanced, tight value, loose passive, and pressure. The first four bot seats receive distinct styles; further seats draw from another shuffled cycle. The assignment stays with each player for the session and survives a saved-game restore.
- The existing cash bot uses small, named shifts to opening, calling, raising, bluffing, and raise size. Tournament play still uses the original strategy.
- Each bot receives its own style through the private seat observation. Other seats' styles are absent from its observation. The hand header and own-seat JSON backup keep the style ID and version for later review.
- Existing snapshots and hand histories without a style continue as balanced. The event schema and prior history remain readable.

## Gate

`node --input-type=module --eval 'import test from "node:test"; globalThis.Deno = { test }; await import("./js/gameEngine.test.js"); await import("./js/bot.test.js"); await import("./js/seatObservation.test.js"); await import("./js/shared/handHistory.test.js");'`

All 84 tests pass. The style test enumerates all 1,326 heads-up starting-card combinations for each of the four profiles. It asserts that pressure raises more often than balanced, balanced raises more often than tight value, loose passive calls more often than balanced, and every generated action is legal.

`node evidence/b2-mixed-style-stress.mjs`

The [mixed-style result](b2-mixed-style-stress-results.json) completed 1,000 six-bot hands at each of 20, 40, 60, 100, 150, and 200BB. No hand stalled, no requested action was rejected, fixed blinds and chip conservation held after every hand. The stress table uses a fixed style draw and seeded cards/actions; it is a structural test, not a strength ranking.

## Limit

The style labels describe deterministic parameter families around one rules bot. They do not claim to model the real population of human opponents. A player has to infer an opponent's style while playing; its ID is available in the saved hand for review. Human-facing hand text and marking are the next T1 node.
