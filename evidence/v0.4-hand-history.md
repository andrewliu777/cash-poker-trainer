# v0.4 private: cash hand-history gate

Date: 2026-09-30. Source branch: `cash-trainer`. This gate covers H1 only; it does not rate bot strategy.

## Delivered

- Every cash hand begins with a versioned header captured before blinds: session/hand ID, dealer, funded seats, starting stacks, fixed blinds, chip unit, no-rake rule, app version, and buy-in/top-up transactions since the previous hand.
- Ordered, detached events record blinds, private hole deals, executed actions with actual paid and street total, board cards, public reveals, uncalled returns, pot payouts, and ending stacks.
- Completed hands are queued synchronously in a localStorage outbox and copied to IndexedDB. The current hand travels with the existing continuation snapshot so the event prefix and game state survive a refresh together.
- Export produces a seat-view JSON backup. Other seats' unrevealed hole cards are `null`; later public reveals remain at their original event positions. Import validates schema, card uniqueness, event order, amounts, settlement, and final stack conservation before saving. Existing stored keys are not overwritten by an import.
- Internal prefix replay reconstructs board, pot, stacks, current street bets, known and revealed cards, folds, and contributions through a chosen event sequence. The visual replay and decision marking UI remain scheduled for P1.

## Verification

- Node-driven Deno tests: 76/76 pass, including a three-way all-in with side pot, an uncalled return, seat-view secrecy and field whitelisting, JSON round-trip, damaged-file rejection, and preblind/top-up header checks.
- Browser: a six-seat cash hand completed; its history exported, remained exportable after refresh and after starting the next hand, and a valid local JSON file imported with an `Imported 1 hands.` result. A live decision continued after refreshing mid-hand.
- Browser after final refund validation: a two-seat hand ended when the small blind folded; the table returned to `New Hand` with correct 2010/1990 stacks and no console warning or error.
- The existing decision-ticket test still rejects stale, duplicate, and wrong-seat actions.

## Limits

- Storage is local to the browser origin/profile; an exported JSON file is the portable backup.
- The download event could not be inspected through browser automation, although the app reported successful export and a later hand could still export the earlier record. The JSON encoder and parser round-trip passed in the pure tests.
- Imported histories retain unknown opponent cards as unknown. A full visual replay UI and audit-only export are outside H1.
