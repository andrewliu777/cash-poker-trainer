# v1.1.11 Losing-hand prompt — 2026-09-30

The losing-hand dialog now offers only **New Hand** and **Copy Text**. New Hand closes the dialog and starts the next hand through the normal session flow. If the session is paused, this explicit choice resumes it; if the human needs chips, the existing top-up prompt appears. Practice uses **New sample**, and an ended session uses **New Session**. Copy Text copies the completed hand text and closes the dialog; a clipboard failure keeps the dialog open for retry. Downloading text remains available in Hand history & replay.

Verification: `node --check` and `git diff --check` passed. The eight JavaScript test modules passed **109/109**. In an isolated local Chrome run, a two-seat hand loss showed exactly `[New Hand, Copy Text]` with New Hand focused. At 390px, document scroll width stayed 390px and the dialog remained within the viewport. New Hand moved from hand 1 to hand 2 and closed the dialog. A second losing hand used a controlled clipboard write to verify that Copy Text supplied formatted hand text and closed the dialog.

No game rules or hand-history format changed. The next DAG node remains D0 data-license and coverage research.
