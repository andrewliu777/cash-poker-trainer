# v0.2 C1: cash engine milestone

Date: 2026-09-29. This is a partial C1 milestone; the browser cash setup and session controls are not included yet.

The engine now accepts a validated cash config with fixed integer blinds, 20–500BB buy-in depth, a top-up threshold and an auto top-up policy. A cash hand never raises blinds. Before the next hand, bots and optionally the human top up to the target stack if below the threshold. Each top-up increases `cashInvested` and appends a transaction; pot winnings do neither. A cash table with fewer than two funded seats waits instead of naming a champion. A manual top-up is valid only between hands. Dealer rotation uses the last dealer seat when that player is temporarily out.

The existing tournament behavior remains the default for states without `gameMode: "cash"`.

Verification: `node --check js/gameEngine.js`, `git diff --check`, and the Node `Deno.test` shim passed. The suite now has 66/66 passing cases, including cash top-up conservation, waiting and re-entry, dealer rotation, and a browserless cash hand at hand 100 with unchanged blinds. Browser integration and offline-disconnected acceptance are still pending v0.2.
