# v1.1.2 explicit play and spectator entry — 2026-09-30

## Scope

Starting a normal cash session requires one named human seat. Menu offers a separate Watch 6 bots action before play. End session remains available while a hand is active; confirmation schedules the session to end after that hand settles, and the menu can cancel the scheduled end.

## Checks

- `node --check js/app.js`, `node --check js/version.js`, and `git diff --check`: passed.
- Five existing test modules via the Node test shim: 90 passed, 0 failed.
- Isolated localhost browser: clicking Start Cash Session with all names empty kept the table in setup, displayed the name prompt, and focused the first seat name.
- Entering Practice Hero and starting dealt a hand with one human and five bots.
- Menu → Watch 6 bots dealt a hand with six named bot seats. During the hand, Menu exposed End after hand and showed a confirmation. Confirming changed the header to Ending after hand; the hand settled, then the header showed Session ended and New Session became available. Browser console contained no warnings or errors.

## Limits

Spectator sessions retain the existing policy of not saving an unfinished session for refresh continuation. Completed hands remain in hand history. The browser check covered scheduling and completion of an end request; cancelling a scheduled end was reviewed in code but not exercised in this run.
