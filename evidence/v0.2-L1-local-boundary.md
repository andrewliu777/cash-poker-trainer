# v0.2 L1: local boundary

Date: 2026-09-29. Base: `acad6594f9c9be0eff906469113f4442c89bd177`.

## Changes

- Main and companion pages no longer load Google Fonts. The main page no longer loads Umami, and its tracking calls were removed.
- All three pages set a same-origin Content Security Policy. External `fetch` calls in the unused original remote-view modules are blocked by `connect-src 'self'`.
- The main runtime always clears `tableId` when starting or restoring a game. It rejects setup with more than one named human seat. Original remote sync code remains dormant for now; it is not part of local training.
- The service worker only intercepts same-origin requests. This commit uses service worker version `2026-09-29-cash-v0.2-local`.

## Verification

- `node --check js/app.js` and `git diff --check` passed.
- The Node `Deno.test` shim ran the engine and bot tests: 62/62 passed.
- Browser at `http://127.0.0.1:8799/index.html`: after refresh, the page exposed the expected CSP and no external script, stylesheet, or preconnect. No console warnings or errors were recorded. Two named humans could not start a game; changing to one human started a game and removed an injected `tableId=old` URL parameter. Table rendering remained usable after font removal.

## Remaining v0.2 gate

The browser test has not simulated an actual disconnected network. C1 cash-game setup and continuous-session behavior are still pending. The existing companion pages are retained but have no supported remote table service in this private version.
